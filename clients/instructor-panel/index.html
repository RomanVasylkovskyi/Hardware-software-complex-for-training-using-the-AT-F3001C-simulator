ОПИС ТА МОЖЛИВОСТІ:

Симулятор польоту X-Plane 11 транслює UDP пакети телеметрії на мережевий порт комплексу. Використовується для проведення тренувань курсантів безпосередньо у кабіні тренажера AT-F3001C.

  • Синхронна трансляція PFD авіагоризонту, висоти, швидкості (20–50 Hz)
  • Live трекінг координат на навігаційній карті UKLL RWY 13
  • Автоматичний моніторинг стабілізованого заходу (ICAO Annex 6)
  • Аналіз параметрів двигуна Lycoming IO-360-L2A
Конфігурація в симуляторі X-Plane 11:
1. Відкрийте меню Settings → Data Output → General Data Output.
2. Праворуч у блоці NETWORK CONFIGURATION увімкніть галочку Send network data output.
3. Введіть IP Address: 127.0.0.1
4. Введіть Port: 49005
5. Натисніть Done у симуляторі для збереження.
