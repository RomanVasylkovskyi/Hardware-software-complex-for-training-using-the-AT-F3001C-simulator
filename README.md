# Програмно-апаратний комплекс для навчання з використанням симулятора AT-F3001C

Стенд AT-F3001C + X-Plane 11 → телеметрія по UDP → мікросервіси (Python / FastAPI) → веб-панель інструктора, ПК студентів і планшети в локальній мережі.

## Архітектура

```
X-Plane 11 ──UDP 49000──► telemetry-service ──WS──┐
                           (парсер DATA, реплей)   ├──► gateway-service :8000 ──WS/HTTP──► панель інструктора,
                           analytics-service ◄─WS─┤     (агрегація, розсилка,             студентські ПК, планшети
                           (фаза польоту, захід,  │      авторизація, статика)
                            попередження, посадка)─┘
```

| Сервіс | Порт | Відповідає за |
| --- | --- | --- |
| `telemetry-service` | UDP 49000 (назовні), 8001 (внутрішній) | Прийом і розбір пакетів X-Plane 11 `DATA`, якість каналів, реплей записаних польотів |
| `analytics-service` | 8003 (внутрішній) | Фаза польоту, стабілізований захід (ICAO Doc 8168 / FAA AC 120-108), попередження, Landing Score |
| `gateway-service` | 8000 (назовні) | Збирає дані телеметрії та аналітики, розсилає клієнтам, проксіює керування, віддає веб-панель |

Назовні публікуються лише UDP 49000 і HTTP 8000. Внутрішні сервіси доступні тільки в мережі Docker, тож авторизацію шлюзу не можна обійти напряму.

## Запуск

```bash
cp .env.example .env        # задати INSTRUCTOR_TOKEN
docker compose up --build
```

- Панель інструктора: `http://<сервер>:8000/`
- Окремі екрани для планшетів: `/?view=pfd`, `/?view=nd`, `/?view=engine`, `/?view=standby`
- X-Plane 11: Settings → Data Output → "Send network data output" на IP сервера, порт `49000`. Потрібні ряди 1, 3, 4, 7, 8, 13, 14, 17, 18, 20, 25, 37, 45, 47, 49, 50, 62 (для автопілота також 102, 103, 108, 117, 118).

## Керування та авторизація

Запуск і зупинка реплею, перемикання на live і завантаження файлів (`POST /api/replay/*`, `/api/mode/live`) вимагають заголовок `X-Instructor-Token`, якщо в `.env` задано `INSTRUCTOR_TOKEN`. Панель запитує токен один раз і зберігає його в браузері інструктора. Потік телеметрії (`/ws/telemetry`) відкритий лише на читання для всіх клієнтів.

## Дані

- `data/telemetry_essential.csv` — політ Cessna 172SP, UKLL, два кола, приблизно 10 Гц.
- Колонки `egt_f` і `oil_temp_f` записано в °F, бо X-Plane 11 віддає EGT і температуру оливи саме так. Сервіс переводить їх у °C.
- З t = 217,6 с X-Plane перестав писати ряди двигуна (у Data.txt стало 560 колонок замість 598, нового заголовка немає). Значення двигуна з цього моменту порожні, а не нулі.
- `on_runway` у X-Plane означає «над поверхнею ЗПС», а не «колеса на землі». Торкання визначається за висотою над землею (`analytics-service/flight_phase.py`).
